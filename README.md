# Harsh Paun — Interior & Spatial Design Portfolio

A residential interior design portfolio presenting three bedrooms in a family home. The single-page website brings together room concepts, material choices, lighting studies, and links to interactive Coohom 360° panoramas.

## Explore the project

Preview the website locally using the steps below. Each room section includes a **View 360 panorama** link for exploring its spatial design.

| Space | Presentation |
| --- | --- |
| Primary bedroom | Room design and an interactive panorama |
| Second bedroom | A separate room concept and panorama |
| Third bedroom | A separate room concept and panorama |

The project description covers modeling to the home's floor plan and measurements, with daytime and evening lighting studies for stone, wood, upholstery, and brass finishes.

## Preview locally

This is a static HTML/CSS portfolio with no package installation or build step.

```sh
git clone https://github.com/techgamewithharsh-dot/portfolio.git
cd portfolio
python3 -m http.server 8080 --bind 127.0.0.1
```

Open **http://localhost:8080**. Stop the preview with `Ctrl+C`.

The page is contained in [index.html](index.html). Google Fonts and the linked Coohom panorama viewers require an internet connection.

## Design and implementation

- Single-page room-by-room presentation.
- Fraunces and Work Sans typography.
- HTML and CSS that can be edited directly.
- External 360° panorama links for each bedroom.
